Terminology consistency

Where one word in the source language has been translated several different ways. Wikidata has no way to see this, because each property is translated on its own — so the same term drifts apart over time. Each finding below is somewhere a language community may want to settle on one wording.

How this is worked out

There is no word-by-word alignment between a label and its translation, so this works by association: for each source word, WDProp looks at the properties whose label contains it and finds which words recur in their translations. A word only counts as a rendering if it is much more common in that group than in the language as a whole, which keeps ordinary frequent words out. Treat the findings as leads to check, not as errors.
