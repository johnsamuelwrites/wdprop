Translation Gap Radar

A live, bounded view of properties still missing one kind of translation. The page asks Wikidata for aggregate coverage and one limited worklist; labels for the visible rows are fetched in one batched API request.

Request budget: two SPARQL requests on load, then one batched entity API request for each visible table page. No worklist state is stored by this page.
