Working offline

The languages whose properties are least translated are, with striking regularity, spoken where the connection is worst. WDProp can hold everything it needs — its own pages, and the whole property vocabulary in the languages you work in — so that translating carries on when nothing is reachable. What you write is kept in this browser and exported when you next have a connection; a batch can also travel as a file, so a room with one connected laptop can collect everybody's work.

This browser

The property vocabulary

About thirteen thousand properties, with their labels, descriptions and aliases in the languages you name. Downloading takes a few minutes and a few megabytes; after that the workbench works with nothing reachable. Name the language you are translating into and the one you read from.

Carrying the batch

A batch saved as a file can be moved to a machine that has a connection and exported to QuickStatements from there. It keeps everything WDProp knows about each proposal, not only the edit, so nothing is lost on the way. Importing merges into the batch already here rather than replacing it, which is what makes it possible to collect several people's work on one machine.
